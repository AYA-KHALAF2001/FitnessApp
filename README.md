# Fitness App 🏋️

An Android fitness tracker built as a group project for CP470 at Wilfrid Laurier University. Users can log workouts, track progress through an XP/leveling system, maintain daily streaks, and manage their profile — all built as a native Android app.

## Demo


## Features

- **User authentication** — login and registration
- **Workout tracking** — log and view workout history
- **Meal planning** — plan and track meals
- **XP & leveling system** — gamified progress tracking
- **Streak tracking** — daily engagement streaks
- **Rank status** — view progress rank each day streak 
- **User profile** — view and update personal info

## Tech Stack

- **Language:** Kotlin, Java
- **Platform:** Android (native)
- **Database:** Firebase
- **IDE:** Android Studio

## My Contribution

This was a group project built collaboratively with two classmates. 
My primary contribution was the **workout tracking and logging system** — including the UI for adding/viewing workouts and the logic connecting it to Firebase for persistent storage.

## Getting Started

1. Clone the repo
2. Open in Android Studio
3. Connect to your own Firebase project
4. Run on an emulator or physical device
